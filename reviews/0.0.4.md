# 0.0.4 release review

Range: `v0.0.3..39aeea4` on `review/2026.11.09` (254 commits: main since v0.0.3, and this week's batch: PR #212, #168's tests, the Dependabot bumps and #265).
1083 tests and lint passed at 39aeea4; after the fixes below, 1094 do.

## How this review was done

Four reviewers, one per dimension in #80's checklist, each working read-only against the same commit. The reviewers were Claude agents, each briefed with the same instructions (the method is in [REVIEWING.md](../REVIEWING.md)); the maintainer chose what to fix, file and set aside from their merged lists.

- **Technical debt:** duplication, dead code, and whether #141's untangling holds: no feature reaching into another, and each one able to be left out.
- **Quality:** tests missing for what changed, found by breaking each line and seeing whether a test fails; lint, naming, docs and README.
- **Correctness:** bugs, especially along the daily journal's path: Today, copying and starting a day's file, versions, `open-until:`, timers, sections' Done.
- **Accessibility:** WCAG 2.2 AA. axe in light, dark, more contrast (light and dark) and forced colours; the accessibility tree, compared with v0.0.3's; keyboard traces through Today, copying, Work's twelve journal pages, the timer, the date picker and the deck's overview; reflow at 320px; target sizes.

Each reviewer was given every open issue and the private security notes, so as not to report what's already known. Each finding was reproduced where it could be, and marked when it was read only. Each reviewer also wrote down what it looked at and decided was *not* a finding.

Then the four lists were merged, the claims checked against the code (the byline, the layout marks and the overview's scroll reproduced again), and each finding given a milestone by three questions:

1. **Is it new in this milestone, and small?** Then fix it before the tag, as a polish of the issue that introduced it. A release shouldn't ship a regression of its own making.
2. **Does it matter for the daily dashboard?** That's what 0.0.4 is for, and `test/fixtures/journal.md` is its acceptance test.
3. **Otherwise, where does it fit?** The milestone whose theme it belongs to, or an existing issue that already covers the same code.

The acceptance test works as it promises, in Chromium at desktop width and in WebKit on a phone, open and closed.

No security findings.

## Set aside, and why

### Already covered

- **The hang and cascade on a failing page assert:** #167's known effect, seen as 156 and 167 failures at once from one broken line.
- **Puzzles on a phone, and dragging with no single-pointer alternative:** #246 (0.0.6); the drag predates the range.
- **The `.gm-who` chip's CSS in the core, a second copy of asides':** comes with the byline drawing reviewers without asides (#195); small.

### Deliberate, or a browser's limit

- **`features/rows.js` is mostly core code:** deliberate in #193.
- **The margin still named `.gm-asides` in the core, and `static/status.js` and `static/markdown.js` knowing `~`:** #195 didn't ask for the rename, and defers them.
- **Frame-side copies of server code** (open-until's closing time, the timer's clock): forced by classic scripts in the frame. Same regex, checked.
- **Today groups only the files dated today,** so a group whose other versions carry other dates is one file there; opening it lands in the right group.
- **The Today button stays pressed after Esc hides the list:** pressing again shows them, as `pressToday` says.
- **At 320px the page bar ellipsises "0 of 12 d…":** by design (#247); the numbers stay, and the bar has its value.
- **An overview refresh announces the highlighted slide once,** as it's a new element; only on returning to the window.
- **Ctrl+G with the overview open says "Slide 1 of 5" before Go to:** redundant, harmless.
- **`--tailscale`'s test skipped on Windows:** deliberate.
- **WebKit's Tab skipping links:** its own setting, as on any page.

### Checked and fine

- **Cross-feature imports:** none, by the lint rule and by grep of paths, CSS and `import.meta.url`. Every `requires` is declared, and checkRequires holds.
- **Leaving out a feature** other than a layout: every docs page, the journal and the sample render, as a page and as an export, with nothing thrown.
- **The asides refactor:** v0.0.3's and 39aeea4's accessibility trees are identical for the notes, layout, text, forms, links and asides docs, in Edit and in Work.
- **Comments and docs naming removed files:** none left; every path resolves. No dead CSS classes.
- **#168's tests:** each fails with its line broken.
- **Dates, content and the server:** 24 of 26 mutations caught, among them invalid dates, `date:` over a name, `--day-starts`, the stale-copy refusals, `-copy-N` names and `open-until:`'s grace.
- **Copy for today's clearing:** choices, cards, `# [x]` headings, dates, numbers, blanks in choices, tabs, tables and quotes cleared; `date:` and `open-until:` moved; `-copy` when today's is there.
- **Start today's from Today with a filter typed:** the file made, Today kept, the new row focused.
- **The room's overview refresh (PR #212):** clamped, highlight and scroll kept, nothing said. Go To closes it first.
- **The timer:** a group named for its length, not live, its buttons keeping the keyboard; time's up said once.
- **Accent colours:** six tried, light and dark: the pill, its fill and the focus ring stay between 5.1:1 and 16:1.
- **Forced colours:** the picked card, the Done pill, progress bars, field lines, the timer, page dots and the gray icons all show.
- **Reflow at 320px:** no sideways scroll anywhere. **Target sizes:** the timer's buttons, page dots and copy icons pass by spacing; the Done pill has its 24px.
- **Work's list over the page (#240):** it closes as focus leaves it, so it never covers what has focus.
- **Docs examples:** every docs page renders with nothing left as typed that should have been drawn; escapes stay as typed.
- **The release notes' issue-for-PR loop:** run by hand against #145, #57, #159 and #170. It isn't tested in CI, so read 0.0.4's notes at the tag.
- **README, install.md's ports and the Docker port docs:** right.

- **Untested, and small:** the copy icons' long press (its helper is tested on New and Start today's); a progress bar's name stopping at a line break; dates.js's tie-break by path.
- **A version dated today counting as today's made** for Start today's: too unlikely. From reading only.
- **Start over says only "saved", and its "↺" has no alt:** predates the range.
- **"Start today's" in Today's list is a plain list item:** small.
- **The filter's only name is its placeholder; task boxes are 13px:** predate the range.
- **axe's remaining hits** (no h1 in the app shell, the masthead's banner, empty table headers in docs' key tables): predate the range, or are the author's.
- **Four radio groups named "Closest word:" on the journal's mood page:** the author's label.
- **#116 closed with two unticked bullets:** the work is done; only the boxes weren't ticked.
- **gh-265's extract cleanup** might be better as `fs.realpathSync.native`; not checkable off Windows.
- **Exports used only in their own files that predate the range:** too small.
